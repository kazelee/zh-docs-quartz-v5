# Quartz v5 教程文档中文翻译

> 本项目完全使用 AI 翻译，没有经过人工校对，不代表官方，仅为个人自用，内容仅供参考。

## 项目说明

1. 使用 DSH 批量翻译，将 `doc/` 下的所有 markdown 文件和 canvas 文件内容翻译，并复制到 `content/` 目录下。
2. 保留原本的文件结构和文件名称，部分文件内容（如标签、链接等）保留英文原文。
3. 修复了部分中文斜体样式没有正常渲染的问题（`_中文_` 周围必须有空格或者符号，否则不会视作斜体）
4. 考虑到[原网站](https://quartz.jzhao.xyz/)一直更新，这里暂时将所有文档的日期改成 `2026-09-20` 以示区别。
5. 调整了部分包含 `#` 的链接，修改为实际的中文标题，使得这些链接能直接跳转到文档的对应位置（没有进一步彻底验证，不保证所有的链接都完美修复）
6. 文档目前的版本基于 [Quartz v5](https://github.com/jackyzha0/quartz) 仓库 [Commit 97a2d05](https://github.com/jackyzha0/quartz/commit/97a2d05f80c4c50534959b1d0d41cc4b3895625e) 版本翻译，大概率不会更新，内容仅供参考。
