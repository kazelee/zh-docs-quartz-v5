恭喜！你已成功解密此页面。🎉

这是 [[EncryptedPages]] 插件的实时演示。你正在阅读的内容在构建时使用 AES-256-GCM 加密，并在你的浏览器中使用 Web Crypto API 解密。此页面还设置了 `unlisted: true`，这意味着在你输入密码之前，它被隐藏在站点的所有发现入口之外。

## 刚刚发生了什么？

1. 在构建时，插件读取了此页面 frontmatter 中的 `password` 字段，并加密了标题以下的所有内容。
2. 由于此页面设置了 `unlisted: true`，插件将其元数据（slug、标题、链接、标签）输出到单独的 `static/encryptedContentIndex.json` 文件中，并使用此页面自己的密码加密。
3. 当你访问此页面时，看到的是密码输入提示，而不是页面内容。此页面不出现在侧边栏关系图谱、资源管理器、搜索、RSS、站点地图、反向链接、标签列表和 bases 视图中。
4. 输入正确的密码后，插件使用 PBKDF2 派生加密密钥，并在客户端解密内容。
5. 随后，插件使用缓存的密码解锁此页面在影子内容索引中的条目，并就地修补内存中的内容索引。系统派发了 `content-index-updated` 事件，因此关系图谱、资源管理器和搜索会使用新解锁的条目重新初始化——如果你现在导航回任何其他页面，就会在侧边栏、关系图谱和搜索结果中看到此页面。服务端渲染的列表（反向链接、最近笔记、标签页面、文件夹列表和 [[BasesPage|bases 视图]]）在构建时已被烘焙进 HTML，不会在本次会话内更新；它们只会在站点重新构建后反映已解密的页面。

## 密码缓存

你的密码已缓存在会话存储中。如果此站点上还有其他使用相同密码的加密页面，插件会自动在每个页面上尝试这个密码——同时解锁其内容和它在影子内容索引中的条目——因此每个会话你只需输入一次密码。

## 自己试一试

要在你自己的 Quartz 站点中添加加密页面，请安装该插件，并在任意页面的 frontmatter 中添加 `password` 字段。完整的设置说明见 [[EncryptedPages]]。
