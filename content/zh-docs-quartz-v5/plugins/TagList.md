本插件将页面的标签渲染为可点击链接的列表。每个标签链接到其对应的 [[TagPage|标签页面]]，方便读者按主题浏览相关内容。

> [!note]
> 有关如何添加、移除或配置插件的信息，请参阅 [[configuration#Plugins|配置]] 页面。

本插件没有配置选项。

## API

- 类别：组件
- 函数名：`ExternalPlugin.TagList()`。
- 来源：[`quartz-community/tag-list`](https://github.com/quartz-community/tag-list)
- 安装：`npx quartz plugin add github:quartz-community/tag-list`
