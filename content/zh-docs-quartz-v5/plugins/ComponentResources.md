本插件管理并输出 Quartz 框架所需的静态资源。这包括 CSS 样式表和 JavaScript 脚本，它们用于增强生成站点的功能与外观。另请参见 [[configuration]] 的 `theme` 部分中的 `cdnCaching` 选项。

> [!note]
> 有关如何添加、移除或配置插件的信息，请参见 [[configuration#Plugins|配置]] 页面。

本插件没有配置选项。

## API

- 类别：输出器
- 函数名：`Plugin.ComponentResources()`（内部插件）。
- 源码：[`quartz/plugins/emitters/componentResources.ts`](https://github.com/jackyzha0/quartz/blob/v5/quartz/plugins/emitters/componentResources.ts)。
