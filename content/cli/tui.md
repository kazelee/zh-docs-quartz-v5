`tui` 命令启动一个用于管理 Quartz 项目的交互式终端用户界面。它提供了一种可视化的方式来管理插件、安排站点布局以及编辑常规设置。

## 前提条件

要使用 TUI，你必须具备以下条件：

1. **Bun**：TUI 需要 Bun 运行时。你可以在 [bun.sh](https://bun.sh/docs/installation) 找到安装说明。
2. **TUI 插件**：你必须在 Quartz 项目中安装 TUI 插件。

### 安装

运行以下命令以添加 TUI 插件：

```shell
npx quartz plugin add github:quartz-community/tui
```

## 界面面板

TUI 分为三个主要面板，你可以在它们之间导航。

### 插件面板

该面板允许你浏览所有可用和已安装的插件。你可以：

- 用一次按键启用或禁用插件。
- 配置插件专属的设置。
- 安装社区中的新插件，或移除已有的插件。

### 布局面板

布局面板用于定义组件在站点中出现的位置。你可以：

- 在不同区域之间移动组件（例如 `left`、`right`、`beforeBody`）。
- 在区域内重新排列组件，以改变它们的垂直堆叠顺序。
- 为组件设置优先级以控制其位置。

### 设置面板

该面板提供了一个集中的位置来编辑你的 `quartz.config.yaml` 设置。你可以更新：

- `pageTitle`
- 主题颜色与字体
- 分析配置
- 部署设置

## 导航

TUI 使用标准的终端导航键：

- **方向键**：在条目和面板之间移动。
- **Enter**：选择条目或确认更改。
- **Esc**：返回或取消操作。
- **Tab**：在不同界面元素之间循环切换。

## 重要提示

TUI 中所做的所有更改都会直接写入你的 `quartz.config.yaml` 文件。在使用 TUI 之前保持 Git 状态干净是一种好习惯，这样你可以轻松查看并撤销它所做的任何更改。

有关基于命令行的插件管理，见 [[cli/plugin|quartz plugin]]。
